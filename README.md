# City Outlaw 3D - GTA Open-World WebGL Game
Complete, self-contained single-player 3D open-world game with both desktop and mobile touch controls.

## Features:
- Procedural City: 5x5 blocks, roads, pavements, buildings with procedural lit windows.
- Vehicles & Traffic: Drivable cars, autonomous AI traffic loops, animated wheels.
- Pedestrian AI: Walking pedestrians, ragdoll on hit, cash pickups.
- Combat & Wanted System: Raycast shooting, muzzle flashes, bullet tracers, 3-star wanted system, Police cruiser chase AI with flashing siren lights.
- Web Audio Synthesizer: Procedural engine sound, siren, gunshots, cash chimes, collisions.
- Dual Controls: Full desktop keyboard/mouse controls + On-screen mobile virtual joystick & touch action buttons.
- LocalStorage Persistence: Cash, score, and kills saved automatically.

## How to Play:
Just open `index.html` in any browser on PC or Mobile!# Parkorgame
